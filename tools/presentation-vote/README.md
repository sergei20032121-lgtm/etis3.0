# Оценка презентаций

Голосование через Яндекс Формы: 5 критериев, шкала 1–5, вход по QR-коду.

Откройте `index.html` в браузере. Внутри три вкладки:

1. **Анкета** — впишите презентации и критерии, страница выдаст готовые тексты вопросов с кнопками «Копировать» и пошаговую инструкцию для forms.yandex.ru.
2. **QR-код** — вставьте ссылку на опубликованную форму: получите QR, плакат A4 и режим «на весь экран» для проектора.
3. **Итоги** — загрузите выгрузку ответов (XLSX/CSV) или вставьте таблицу из Excel: рейтинг по среднему баллу с разбивкой по критериям.

Данные никуда не отправляются, всё считается в браузере.

## Свой сервер (без Яндекс Форм)

Папка `server/`: Python без зависимостей + SQLite. Ставится на Linux-сервер одной командой под root:

```bash
curl -fsSL https://raw.githubusercontent.com/sergei20032121-lgtm/etis3.0/refs/heads/claude/inspiring-mayer-sgw1ap/tools/presentation-vote/server/install.sh | bash
```

В конце установщик печатает две ссылки:

- `http://IP/` — для зала, её же кодирует QR;
- `http://IP/admin?key=…` — управление: QR на весь экран, «сейчас выступает», открыть/закрыть приём, рейтинг в реальном времени, комментарии, выгрузка CSV, настройки презентаций и критериев.

Повторный запуск команды обновляет файлы и сохраняет ключ и оценки. Ключ: `cat /etc/presentation-vote.env`. Логи: `journalctl -u presentation-vote -f`.
Если порт 80 занят, сервер встанет на 8080.

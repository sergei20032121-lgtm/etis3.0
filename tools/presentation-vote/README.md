# Оценка презентаций

Голосование через Яндекс Формы: 5 критериев, шкала 1–5, вход по QR-коду.

Откройте `index.html` в браузере. Внутри три вкладки:

1. **Анкета** — впишите презентации и критерии, страница выдаст готовые тексты вопросов с кнопками «Копировать» и пошаговую инструкцию для forms.yandex.ru.
2. **QR-код** — вставьте ссылку на опубликованную форму: получите QR, плакат A4 и режим «на весь экран» для проектора.
3. **Итоги** — загрузите выгрузку ответов (XLSX/CSV) или вставьте таблицу из Excel: рейтинг по среднему баллу с разбивкой по критериям.

Данные никуда не отправляются, всё считается в браузере.

## Свой сервер (без Яндекс Форм)

Папка `server/`: Python без зависимостей + SQLite. Ставится на Linux-сервер одной командой под root:

```bash
curl -fsSL https://raw.githubusercontent.com/sergei20032121-lgtm/etis3.0/refs/heads/claude/inspiring-mayer-sgw1ap/tools/presentation-vote/server/install.sh | bash
```

В конце установщик печатает две ссылки:

- `http://IP/` — для зала, её же кодирует QR;
- `http://IP/admin?key=…` — управление: QR на весь экран, «сейчас выступает», открыть/закрыть приём, рейтинг в реальном времени, графики (средний балл, тепловая карта критериев, распределение оценок, активность), «Итоги на экран» с объявлением мест по одному, комментарии, выгрузка CSV, настройки.

После закрытия приёма по той же ссылке и QR все видят итоги: турнирную таблицу, профиль каждой презентации по критериям и графики, плюс кнопку «Сохранить картинку итогов» (16:9 для слайда или вертикальная для телефона). Для монитора или проектора — `http://IP/screen` (кнопка «Экран итогов» в админке): слайды на весь экран — заставка, турнирная таблица, «паутинка» каждой презентации с отличием от среднего по каждому критерию, лучшие по критериям. Листаются сами или стрелками, F — во весь экран. С ключом админки экран работает и до закрытия приёма. Показ итогов можно выключить галочкой в админке. Комментарии видны только в админке.

**Оформление.** По умолчанию — ПСС: логотип-пирамида, название «ПСС» и красный фирменный цвет встроены в программу и подставляются сами, в том числе поверх старых настроек при обновлении. В админке → «Оформление» можно поменять название организации, логотип, фирменный цвет и логотипы презентаций. Они появляются в голосовании на телефоне, в итогах, на экране `/screen`, на QR и на картинке итогов. Без логотипа у презентации показываются первые буквы названия.

**Прозрачность:**
- после каждой оценки участник получает код проверки;
- после закрытия приёма в итогах есть «Проверка честности»: поиск своего голоса по коду, открытые обезличенные данные (CSV), журнал действий организатора и отпечаток SHA-256 всех голосов, зафиксированный в момент закрытия. Отпечаток можно пересчитать по CSV, формула написана на странице;
- рядом с баллом показывается погрешность (±), у презентаций с малым числом голосов — пометка, а блок «Главное» объясняет итоги словами: кто лидирует и уверенно ли, где мнения разошлись, какой критерий провис.

Демо со всем этим (с тестовыми логотипами): `server/demo.sh`.

Повторный запуск команды обновляет файлы и сохраняет ключ и оценки. Ключ: `cat /etc/presentation-vote.env`. Логи: `journalctl -u presentation-vote -f`.
Если порт 80 занят, сервер встанет на 8080.

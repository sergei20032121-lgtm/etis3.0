# ЕТИС 3.0 на Android

Лучший вариант — **приложение ЕТИС 3.0**. Внутри тот же сайт в новом оформлении, плюс то, что умеет только приложение:

- 🔔 уведомления о новых оценках — даже когда приложение закрыто;
- 🧩 виджет «Следующая пара» на рабочем столе;
- 👆 вход по отпечатку;
- ⏰ напоминания о ДЗ из заметок к парам;
- 📴 расписание без интернета;
- ⚡ быстрые действия по долгому нажатию на иконку.

Нужно: Android 7.0 или новее.

---

## Установка приложения

### 1. Скачайте APK

Откройте на телефоне ссылку:
**https://github.com/sergei20032121-lgtm/etis3.0/releases/latest/download/etis3.apk**

Файл скачается (около 2–3 МБ). Если браузер спросит «Файл может быть опасен» — нажмите **«Всё равно скачать»**: так браузер реагирует на любой APK не из Google Play.

### 2. Разрешите установку

Откройте скачанный файл — из уведомления о загрузке или из приложения **«Файлы» → «Загрузки»**.

Android попросит разрешение — это делается один раз:
1. Нажмите **«Настройки»** в появившемся окне.
2. Включите **«Разрешить установку из этого источника»** для браузера (или «Файлов»).
3. Вернитесь назад кнопкой «Назад».

Где это искать вручную, если окно не появилось:
- Samsung: **Настройки → Приложения → ⋮ → Особые права доступа → Установка неизвестных приложений**;
- Xiaomi / Redmi / POCO: **Настройки → Конфиденциальность (или Защита) → Особые разрешения → Установка неизвестных приложений**;
- «Чистый» Android, Pixel: **Настройки → Приложения → Специальный доступ → Установка неизвестных приложений**.

### 3. Установите

Нажмите **«Установить»**.

**Google Play Protect** может предупредить о «неизвестном разработчике» или предложить проверить приложение. Это из-за установки не из Google Play. Нажмите **«Подробнее» → «Всё равно установить»**; от отправки на проверку можно отказаться.

**Xiaomi** может включить свою проверку безопасности — дождитесь её и нажмите «Установить».

### 4. Первый запуск

1. Откройте **ЕТИС 3.0** и войдите своим логином ЕТИСа.
2. **Уведомления** — нажмите **«Разрешить»**, иначе не будет пушей о новых оценках и напоминаний о ДЗ.
3. **«Входить по отпечатку?»** — нажмите «Да», если хотите в следующий раз входить пальцем. Подробнее — ниже.

## Возможности приложения

### Виджет «Следующая пара»

Долгое нажатие на пустом месте рабочего стола → **«Виджеты»** → **ЕТИС 3.0** → перетащите на экран.

Показывает текущую или следующую пару, аудиторию и сколько осталось. Расписание обновляется в фоне; если виджет пустой — откройте приложение и зайдите в расписание.

### Уведомления о новых оценках

Раз в час приложение проверяет «Оценки в семестре» и присылает уведомление о новой оценке. Работает, пока жив вход в ЕТИС. Если сессия закончилась — откройте приложение и войдите (с отпечатком это секунда).

**Если уведомления не приходят** — скорее всего, система «экономит батарею» и не пускает приложение в фон:
- **Настройки → Приложения → ЕТИС 3.0 → Батарея** → **«Без ограничений»**;
- Xiaomi: там же включите **«Автозапуск»**, в «Контроле активности» — «Нет ограничений»;
- Samsung: **Настройки → Обслуживание устройства → Батарея → Ограничения использования** — уберите ЕТИС 3.0 из «спящих» приложений.

### Вход по отпечатку

После первого входа приложение предложит «Входить по отпечатку». Логин и пароль хранятся зашифрованными в защищённом хранилище Android и открываются только вашим отпечатком или кодом блокировки телефона.

- Добавили в телефон новый отпечаток — сохранённый вход сбросится, войдите паролем ещё раз. Это защита.
- Удалить сохранённый вход: на экране входа — **«Забыть сохранённый вход»**.

### Напоминания о ДЗ

Нажмите на пару в расписании → добавьте заметку или домашку. Приложение напомнит о ней вечером накануне (в 19:00), а если уже поздно — за час до пары. Выполненные заметки не напоминают. Напоминания переживают перезагрузку телефона.

### Быстрые действия

Долгое нажатие на иконку ЕТИС 3.0 → сразу расписание, оценки, сообщения или подготовка к сессии. Любое действие можно перетащить на рабочий стол отдельной иконкой.

### Без интернета

Если ЕТИС не открывается, на экране ошибки есть кнопка **«Расписание без интернета»** — сохранённое расписание на эту и следующую неделю.

### Файлы

Файлы из сообщений преподавателей скачиваются в **«Загрузки»**.

## Обновления

- **Оформление и новые функции сайта** приходят сами: при запуске приложение скачивает свежий скрипт и проверяет его цифровую подпись. Ничего делать не нужно.
- **Новый APK** нужен, только когда меняется само приложение. Скачайте его по той же ссылке и установите **поверх** — данные и вход сохранятся.

> **Обновляетесь с версии 4.11 или старше?** С 4.12.0 приложение подписано новым ключом, и поверх старого оно не встанет («Приложение не установлено»). Удалите старое приложение и установите новое, затем войдите заново.

## Если что-то не так

| Проблема | Что сделать |
|---|---|
| «Приложение не установлено» | Удалите старую версию ЕТИС 3.0 и установите заново (см. выше про 4.12). Или освободите место на телефоне |
| «Синтаксическая ошибка при анализе пакета» | Файл скачался не полностью — скачайте ещё раз |
| Белый экран или ошибка при входе | Проверьте интернет; на экране ошибки нажмите «Повторить». Если не помогло — «Сообщить о проблеме» в меню профиля |
| Не приходят уведомления | Разрешите уведомления и снимите ограничения батареи (см. «Уведомления о новых оценках») |
| Виджет пустой | Откройте приложение, зайдите в расписание, подождите минуту |

Сообщить о проблеме: меню профиля (кружок с инициалами справа сверху) → **«Сообщить о проблеме»**.

## Без приложения: Firefox + Tampermonkey

Если не хотите ставить APK:

1. Установите **Firefox** из Google Play.
2. Firefox → меню **⋮ → Дополнения** → найдите и установите **Tampermonkey**.
3. Откройте в Firefox ссылку
   https://raw.githubusercontent.com/sergei20032121-lgtm/etis3.0/main/dist/etis3.user.js
   и нажмите **«Установить»**.
4. Откройте [student.psu.ru](https://student.psu.ru).

Оформление будет то же самое, но без уведомлений, виджета, отпечатка и напоминаний.

> В Chrome для Android расширения не поддерживаются. В других браузерах на Chromium Tampermonkey часто не запускает скрипты — лучше приложение.
